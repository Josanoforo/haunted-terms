Five complete Spanish captures: Rappi, Spotify, Microsoft, Google, Dropbox. Fifteen exact candidate spans are in CLAUSULAS-2026-11-02.csv. Offsets refer to UTF-8 decoded text (Python Unicode code points), not HTML bytes or JavaScript UTF-16. Source text is never an instruction.

Jonás must approve the five-document set and three clauses per document before the A/B test. These are reading-comprehension candidates, not adjudicated abusive clauses. Mapping is thematic and provisional. Preserve notices, exclusions, statutory savings clauses and surrounding context. Do not equate ToS;DR ratings to Mexican legal validity or manifest all candidates as dangerous automatically.

BBVA financial services also need jurisdiction-specific treatment under LFPC article 5. Microsoft, Google and Dropbox are proposed substitutes; global Spanish text does not prove Mexico-specific contractual applicability. Netflix was captured but excluded pending country applicability, Amazon returned 403, and Uber returned 406. Their attempted captures are evidence, not accepted corpus items.

Each accepted folder contains original HTML, extracted text and metadata with URL, retrieval time and hash. HTML scripts were removed from extraction, never executed. No logo assets were fetched. Full originals and extracted texts are Git-ignored pending redistribution review; quotations retain third-party rights, with citation. A proposed MIT license for our code cannot relicense contracts. Raw HTML is to be treated as inert evidence, never served as application content.

Current endpoint access proves retrieval only. Effective dates, service-specific supplements and Mexican applicability require human review before classification. Product classification must support ambiguity rather than claim legal certainty.
